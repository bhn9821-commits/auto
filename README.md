### 연체자 최신화 OBT

- 이번 주 연체자 엑셀 목록을 규격화된 관리 파일로 가공
- 저번 주의 가공 대장을 이번 주 원본과 대조하여 최신화
- 통계, 경계선, 셀 서식, 틀 고정 등 업무용 양식 적용
- 2026-10-27: 작업 범위 A~L열 제한으로 비정상적인 엑셀 용량 증가 방지
- 2026-10-28: 기타 인원수 계산을 L열(비고) 기준으로 수정
- 2026-11-26: 화면에 `Made by 김경태` 표시

프로그램 HTML을 다운로드해 웹 브라우저에서 열어 사용합니다. 초기 실행 시 Pyodide 및 Python 패키지 로딩을 위해 인터넷 연결이 필요합니다. 업무용 파일에 대한 실제 실행 검증은 별도 수행하세요.

### 연체자 메시지 자동화 CBT

- 연체자 엑셀 내용을 붙여넣어 문자 메시지·비고 문구 생성
- 이용자별 도서 권수 합산, 날짜별 연체일 보정, 복사 및 텍스트 수정
- 기존 최상위 파일명은 **기존 링크와 사용 습관을 유지하기 위해 보존**했습니다.

## 저장소 관리 원칙

1. 연체자 최신화 프로그램의 기준 소스는 `overdue-update/index.html`입니다.
2. 메시지 자동화 프로그램의 기준 소스는 저장소 최상위의 `연체자 메시지 자동 CBT ver (10).html`입니다. 향후 정리하더라도 기존 링크 영향부터 확인합니다.
3. 두 프로그램의 패치 이력은 각 `CHANGELOG.md`에 별도로 기록합니다.
4. **이 저장소는 공개 저장소입니다.** 실제 이용자의 성명, 연락처, 대출정보가 들어 있는 엑셀/CSV, 업무 결과물, 인증정보, 비밀번호 등을 업로드하지 마세요.
5. 소스 수정 시 변경 목적, 영향 범위, 점검 항목을 커밋 또는 변경 이력에 남깁니다.
