연체자 메시지 자동화 패치내역

v1.0 — 도서관 전용 양식 적용 및 엑셀 연동 기초

도서관 전용 템플릿 구현: 연체 안내, 스마트도서관, 변상 요청, 분실 변상 등 규격 문자 4종 및 비고 6종 템플릿 탑재

엑셀 행 데이터(TSV) 복사·붙여넣기 지원: 엑셀 데이터를 붙여넣으면 탭(\t) 단위로 분 분석하도록 구현

대출 권수 자동 집계: 회원번호 및 이름을 식별값으로 묶어 동일 이용자의 대출 도서 권수를 자동 합산

v1.1 — 날짜 보정 로직 도입

기준 화요일 기반 연체일 계산: 파일 생성일과 실제 발송일의 일수 차이(수요일 +1일, 목요일 +2일)를 자동 계산

주간 초기화 구조: 다음 주 화요일 도래 시 기준일과 발송일이 일치하여 보정치가 자동으로 초기화되도록 구성

v2.0 — UI 개편 및 개별 원클릭 복사 도입

그리드 레이아웃 전환: 드롭다운 방식에서 벗어나 [📱 문자 메시지 4종]과 [📝 비고 6종]을 한 화면에 나란히 배치

개별 복사 버튼 탑재: 필요한 문구 옆의 [복사] 버튼 클릭 즉시 클립보드 복사 지원

명칭 정비: 기준일 라벨을 '연체자 파일 최초 생성일'로 명확화

v2.1 — 연체 일수 산출 로직 정상화

엑셀 최종 열 연체일 기준 파싱: 대출일시/반납일시 기반 계산 대신 엑셀 우측 끝단에 명시된 기존 연체일 숫자를 기준값으로 파싱

일수 가산 정상화: 엑셀의 원본 연체일에 작업 경과일수(+N일)만 정확히 가산되도록 수정

v2.2 — 업무 규칙 및 동선 최적화

180일 이상 변상 안내 재배치: 변상 안내 문구를 문자 목록 최하단으로 이동하고 ⚠️ 180일 이상시 사용 빨간색 태그 부착

비고란 동선 단축: 실무 통화 부재 빈도를 고려하여 통화 x 항목을 비고 리스트 최상단으로 재배치

v2.3 — 사전 경고 및 실시간 텍스트 편집 기능

공통 주의 배너 추가: 화면 상단에 추가 연체건 확인 안내 문구 명시

인라인 편집(contenteditable) 적용: 긴 연체일이나 권수 변동 시 화면 텍스트를 직접 클릭해 수정 후 복사 가능하도록 개선

v2.4 — 예외 처리 및 안정성 패치

연체일 이상치 감지: 1,000일 초과 수치나 누락 발생 시 개별 카드에 🚨 연체일 오류 주의 경고 배너 출력

특수문자 보안 처리: 이용자명 및 소속명의 HTML 특수문자(<, >, &)를 치환하는 escapeHtml 적용

줄바꿈 정돈 로직: 화면에서 직접 수정한 후 복사할 때 줄바꿈이 과도하게 늘어나는 현상 정규식 정제

v2.5 — 사용성 및 온보딩 강화

가이드 블록 배치: 메인 입력창 상단에 📖 사용방법 및 예시 안내 카드 상시 노출

샘플 데이터 로더: 클릭 한 번으로 테스트 데이터를 입력하고 결과를 확인할 수 있는 [샘플 데이터 불러오기] 버튼 탑재

v2.6 — 연번 열 자동 판별 및 데이터 분리 오류 해결

연번(1, 2, 3...) 유무 자동 감지: 맨 앞 열의 연번 유무를 확인해 10자리 이상 회원번호가 있는 위치로 열 기준을 자동 정렬

동일인 분리 버그 픽스: 첫 줄에만 연번이 있고 다음 줄은 빈칸인 복합 엑셀 양식에서도 동일인 데이터가 쪼개지지 않고 한 카드로 정상 합산되도록 처리
