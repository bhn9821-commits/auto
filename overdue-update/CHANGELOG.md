# 연체자 최신화 OBT 변경 기록

> 이 문서는 기존 「자동화 파일 패치노트」에 기록된 연체자 양식·최신화 기능 변경과 2026년 10월 수정 사항을 정리한 것입니다. 버전 번호는 과거 기록의 표기를 따르며, Git 태그를 의미하지 않습니다.

| --- | --- |
| v1.0 | 브라우저 내 Pyodide·openpyxl 연동, 주간 대장 비교·반납 상태 업데이트 |

## 2026-10-27 — 파일 용량 급증 방지
- 주간 연체자 대장 최신화 시 작업 범위를 실제 업무 표의 A~L열로 제한하도록 수정한 별도 수정본이 존재합니다.
- 기존에 파일 크기가 약 40KB에서 약 4MB로 증가한 문제에 대응한 변경입니다.
- 특정 실제 업무 파일에서의 완전한 회귀 테스트가 이루어졌다는 의미는 아닙니다.

## 2026-10-28 — 기타 수 계산 열 수정
- 기존 M열 참조를 비고 열인 L열로 변경했습니다.
- 변경 수식: `=COUNTIF(L:L,"*기타*")&"명"`
- 신규 연체자 대장 생성과 기존 대장 최신화 양쪽에 반영했습니다.

## 2026-11-26 — 제작자 표기 추가
- 프로그램 화면 하단에 `Made by 김경태`를 표시했습니다.
- 기존 10월 27일 용량 방지 및 10월 28일 기타 집계 열 수정은 그대로 유지합니다.
